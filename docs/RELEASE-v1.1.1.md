# 每日一记吧 v1.1.1

睡前用两三句话记下今天的事或心情，保存后安心关机。

## 下载

普通用户下载本页附件 **DailyReflection-v1.1.1-windows-portable.zip**，解压后双击 **每日一记吧.exe**，无需安装。保留旁边的 `.exe.config` 文件。

支持 Windows 10 / 11，需要 .NET Framework 4.7.2 或更高版本。GitHub 自动附带的 Source code (zip) 是开发者源码。

## 本版功能

- 每天保存一条本机记录，支持历史筛选、修改和 Markdown 导出。
- 保存成功后开始 10 秒关机倒计时，可取消，也可以只保存。
- 每次打开输入框为空，原有记录保留在历史记录中。
- 内置 30 条诗句，显示作者和作品来源；毛泽东诗词抽取概率为 60%。
- 离线使用，无需账号。

每天从程序入口开始关机，填写后点击「保存并关机」。记录保存在程序旁边的 `数据` 文件夹，更新前请先备份。

便携包不含任何个人日记。提供同名 SHA-256 校验文件。采用 MIT 许可，并保留第三方许可声明。
