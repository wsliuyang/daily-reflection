# 每日一记吧 · 使用说明

睡前用两三句话留下今天的事或心情，保存后安心关机。

## 开始使用

将便携 ZIP 解压到有写入权限的固定文件夹，双击 **每日一记吧.exe**。程序旁边的 **每日一记吧.exe.config** 是运行配置，请一起保留。

右键点击任务栏上出现的程序图标，选择 **固定到任务栏**，以后每天从这里打开。移动程序文件夹后，需要从新位置打开并重新固定。

运行环境为 Windows 10 / 11 和 .NET Framework 4.7.2 或更高版本，无需安装开发工具。

## 每天使用

- **保存并关机**：先保存记录，再开始 10 秒倒计时，到期请求 Windows 正常关机。
- **取消关机**：点击按钮、按 Esc，或者关闭倒计时窗口。已经保存的记录会保留。
- **只保存**：保存记录并继续使用电脑。
- **历史记录**：按日期查看，输入日期或关键词筛选，修改旧记录，或导出全部记录为 Markdown。
- **Ctrl + Enter**：保存并关机。

每次重新打开程序，输入框为空，已保存的内容可以在「历史记录」查看。每个日期保存一条记录，当天填写新内容再次保存会更新已有记录。空白输入不会覆盖记录，也不会启动关机。窗口跨日使用时会切换到当前日期，保留正在输入的草稿。

顶部诗句从 30 条内置诗句中随机选择，后面显示作者，鼠标停留可查看作品名。每次重新打开程序会重新抽取；再次启动已打开的程序时也会换一句。毛泽东诗词的抽取概率为 60%，其余 40% 来自其他作者，可能连续抽到同一句。诗词功能完全离线。

每天从本程序开始关机：打开窗口，填写记录，再点「保存并关机」。当前版本未接入 Windows 开始菜单的关机入口。

程序采用正常关机。其他软件若有未保存的文件，Windows 可能显示保存提示，处理后才会完成关机。

## 记录和备份

数据保存在程序旁边的 **数据** 文件夹中，首次保存时自动创建：

```text
程序文件夹/
  每日一记吧.exe
  每日一记吧.exe.config
  数据/
    entries.json
    entries.backup.json
    entries.lock
```

- `entries.json`：全部记录，UTF-8 格式，包含日期、内容和保存时间。
- `entries.backup.json`：上一次成功保存前的版本，从第二次保存开始生成。
- `entries.lock`：防止两个写入操作同时修改记录的小文件。

关闭程序后，复制整个 **数据** 文件夹即可备份或迁移。更新时先备份记录，解压新版，再把原来的 **数据** 文件夹复制到新版程序旁边。需要重新固定任务栏时，从新版程序位置打开并固定。

程序不联网，不需要账号。记录是本机明文文件，任何能访问该文件夹的人都可以读取。

写入失败时不会启动关机。记录文件损坏时程序会保留原文件，并提示检查备份。恢复方法：关闭程序，复制整个数据文件夹留作备份，再用 `entries.backup.json` 的副本替换 `entries.json`；恢复后会回到上一次保存的版本。
